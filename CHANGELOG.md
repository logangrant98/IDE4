# Releases

## 0.4.22

- Agent results and conversations switch with a smooth horizontal slide, keeping the header and message box stationary. Reduced motion switches views immediately.
- Colored panes keep a continuous accent edge and tint in both chat and completed-result views. Working indicators and tab highlights follow the selected pane color.
- Vercel connections let you browse hosted projects, deployments, domains, and build logs from IDE4.
- Sending from a result preview clears the submitted draft and prevents repeated submissions while preserving your next message.
- Connection cards keep their pending-state text within the card at narrow widths.

Includes the richer file editor and File Assistant from 0.4.19. All offline voice components, optional shortcuts, fresh-profile onboarding, and GitHub updates remain included.

## 0.4.19

Adds a richer file editor and an assistant that can locate project files, find text, and highlight requested lines. Direct installation with fewer disk writes, compression tuned for installation speed, visible file progress, working Cancel and Close controls, and bounded write failures. All offline voice components remain included. Fresh profiles start without sample projects, agents, saved chats, logs, or memories. GitHub and GitLab update sources are supported. Desktop and Start menu shortcuts remain optional.
