# Releases

## 0.4.19

Adds a richer file editor and an assistant that can locate project files, find text, and highlight requested lines. Direct installation with fewer disk writes, compression tuned for installation speed, visible file progress, working Cancel and Close controls, and bounded write failures. All offline voice components remain included. Fresh profiles start without sample projects, agents, saved chats, logs, or memories. GitHub and GitLab update sources are supported. Desktop and Start menu shortcuts remain optional.
