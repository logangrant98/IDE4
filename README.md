# IDE4

![IDE4](icon.png)

A local workspace for Codex and Claude Code, with voice controls and agent teams.

[Download IDE4 0.4.22 for Windows](https://github.com/logangrant98/IDE4/releases/download/v0.4.22/IDE4-Setup-0.4.22.exe)

## Install

1. Download **IDE4-Setup-0.4.22.exe** from the latest release.
2. Run setup, choose your folder, and select any shortcuts you want.
3. Open **IDE4**, enter your name and optional profile image, then connect your services.

Your profile, memory, projects, and conversations stay on your computer. AI providers process the prompts you send to them under your own account. Offline voice models are included, so the installer is a large download. Allow at least 8 GB free for the downloaded installer, installed application, and local agent service, plus space for your projects.

Click the version number inside IDE4 to check for updates. Downloads come from this repository's Releases page and are verified against the release checksum.

## Setup help

The progress text shows the file being installed. Cancel or the window Close button stops setup; if interrupted, run setup again to finish installation. Setup does not delete your projects or profile.
